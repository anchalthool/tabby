# Drop your Flaticon SVGs here

The UI already looks for these files. Until a file exists, that icon shows a
matching emoji automatically, so nothing ever looks broken. As soon as you add
the SVG, it replaces the emoji and is centered inside its circle.

Use SVG (recommended) so the icons stay crisp. Keep the original artwork —
no need to recolor.

## Food  ->  public/icons/food/
From https://www.flaticon.com/packs/gastronomy-set?word=food
Name the files exactly:

  tomato.svg      milk.svg        bread.svg       pizza.svg
  pasta.svg       water.svg       chocolate.svg   strawberry.svg
  carrot.svg      banana.svg      apple.svg       egg.svg
  cheese.svg      chicken.svg     paper-towel.svg household.svg
  vegetables.svg  avocado.svg     groceries.svg   <- groceries.svg is the fallback

(Not every name needs an exact match in the pack — pick the closest icon and
rename it. `groceries.svg` is used for anything unrecognized, so include it.)

## People  ->  public/icons/people/
From https://www.flaticon.com/packs/people-128
Name them person-1.svg through person-8.svg:

  person-1.svg  person-2.svg  person-3.svg  person-4.svg
  person-5.svg  person-6.svg  person-7.svg  person-8.svg

Each friend is assigned one of these 1-8 slots consistently by their name.
